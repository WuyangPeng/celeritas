一、安装docker

1.执行下面三条命令。
yum install -y yum-utils device-mapper-persistent-data lvm2

yum-config-manager --add-repo https://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo

yum install docker-ce

如果执行第三条语句失败，根据错误提示执行类似下面的命令（--alloyyywerasing 不同机器可能需要不同参数）

yum install --alloyyywerasing docker-ce

执行docker version，查看是否安装docker成功。

2.将docker默认安装路径从/var/lib下移动到/data下。

（1）开启然后关闭docker，docker必须开启过才会在/var/lib下生成目录。
systemctl start docker

systemctl stop docker

（2）迁移数据

mv /var/lib/docker /data/

（3）制作目录链接

ln -s /data/docker /var/lib/docker

（4）查看是否成功

cd /var/lib
ll
其中一条会出现
lrwxrwxrwx 1 root root 12 Feb 17 21:40 docker -> /data/docker

3.启动docker

systemctl start docker

4.设置docker开机自启动

systemctl enable docker.service
